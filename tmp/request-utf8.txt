Продукт не должен обещать пользователю гарантированное наличие электричества.

MR Electro AI helps people explore power infrastructure, understand regional electricity resilience and monitor available changes in power conditions.

Сервис должен чётко разделять:

## Liquid Glass

Liquid Glass означает:

* полупрозрачные поверхности;
* backdrop blur;
* мягкие внутренние блики;
* тонкие светлые границы;
* плавные скругления;
* ощущение глубины;
* аккуратные отражения;
* мягкое наложение слоёв;
* отсутствие тяжёлых чёрных теней.

Пример базовой glass-поверхности:

```css
.glass-panel {
  background:
    linear-gradient(
      145deg,
      rgba(255, 255, 255, 0.78),
      rgba(240, 255, 253, 0.5)
    );
  border: 1px solid rgba(255, 255, 255, 0.72);
  box-shadow:
    0 20px 60px rgba(10, 66, 75, 0.12),
    inset 0 1px 0 rgba(255, 255, 255, 0.9);
  backdrop-filter: blur(22px) saturate(135%);
  -webkit-backdrop-filter: blur(22px) saturate(135%);
}
```

Обязательно предусмотреть fallback для браузеров без backdrop-filter:

```css
@supports not (backdrop-filter: blur(1px)) {
  .glass-panel {
    background: rgba(247, 253, 253, 0.96);
  }
}
```

Не применять сильный blur ко всей странице.

Не использовать Liquid Glass на каждом маленьком элементе.

Использовать glass-эффект для:

* navigation;
* floating map panels;
* station details drawer;
* search;
* filter panel;
* pricing highlight;
* hero preview;
* mobile bottom sheet.

Обычные информационные секции могут иметь непрозрачный светлый фон.
