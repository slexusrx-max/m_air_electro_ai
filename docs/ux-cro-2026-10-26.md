## Implemented scope

- Homepage: compact header mark, visible mobile value proposition/CTA, short disclosure, value strip, three editable examples, featured equipment before categories, then tools and partner/publisher information. The approved artwork/background is unchanged.
- Marketplace and category pages: compact entry and filters/results before secondary category navigation. Raw supplier entries and reviewed models have distinct presentation and result counts.
- Main search: all 365 official Renogy SKU identities are searchable. Only exact provider/SKU matches are deduplicated against canonical models. Feed names support conservative family classification; unknown/service/promotion rows remain searchable without an equipment classification. No technical specifications, compatibility or model photographs are inferred from names or parent pages.
- Prices: latest fresh provider/catalog snapshot only, exact numeric SKU, positive EUR amount, maximum 48-hour retrieval age, malformed/duplicate rejection. A newer invalid or missing value cannot resurrect an older price. Only documented SKU identities enter the public feed map. Ordinary raw-feed links remain untracked. - Comparison: category first, 2–4 actual models, no mixed-family/class-guide equivalence. Existing persistent tray now enforces the same category and retains names/removal/language persistence.

- Navigation/footer: four primary destinations, grouped secondary routes, reduced repetition, retained legal/editorial links and publisher/contact identity. Account menus remain keyboard operable.
- Learn retains planning-class references in a separate expandable section; removing them from default purchase results does not orphan their public pages. Product metadata is model-specific and matches editorial structured data.

## External dependencies

The 18 October downloaded archive is not a current price source. Numeric production prices require authenticated access to a currently retrievable official supplier feed (or a controlled snapshot younger than 48 hours). Without that, the correct public result is a supplier-price link for each missing SKU. This release does not fabricate numbers or activate a scheduled feed service. Model-exact PECRON/BLUETTI image permission and optional publisher biography/portrait remain external inputs; missing fields remain absent.

No affiliate settings, contact delivery, orders, account creation or merchant-side tracking tests are performed. Public href inspection is not proof of commissions.
